# 🦆 Ducky Tools

LUCKY DUCKY의 오리 도구 모음입니다. 아래 셋업 파일 하나로 원하는 도구만 골라 설치하세요.

## 📥 다운로드

**[DUCKY-TOOLS-Setup.exe](https://github.com/Lucky-Ducky87/Ducky-Tools/releases/download/duck-house/DUCKY-TOOLS-Setup.exe)** ← 이거 하나만 받으면 됩니다

실행하면 오리들의 집(DUCK HOUSE)이 열리고, 필요한 도구를 골라 "데려오기"로 설치할 수 있습니다.
모든 도구는 설치 후 자동으로 업데이트됩니다.

## 🦆 도구 목록

| 도구 | 설명 |
|---|---|
| 📝 MEMO DUCK | 화면 가장자리에서 빼꼼 나오는 포스트잇 메모 |
| ⏰ TIMER DUCK | 예약 종료·재시작·절전·알람 타이머 |
| 📷 CAPTURE DUCK | 영역 캡처 + 주석 + 자동 저장 |
| 💛 CUTE DUCK | 바탕화면을 돌아다니는 바보 오리 펫 |
| 📅 CALENDAR DUCK | 구글 캘린더 연동 달력 위젯 |
| ☔ WEATHER DUCK | 오리가 알려주는 날씨 위젯 (날씨별 오리 변신) |
| 🏠 DUCK HOUSE | 위 도구들을 관리하는 오리들의 집 |

이 저장소는 설치파일 배포용입니다.
